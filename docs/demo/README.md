# Demo videos

These narrated recordings show how to find an available dentist, book a visit, and verify a saved appointment in the Dental Appointment Agent.

## AWS deployment walkthrough · 1 minute

The laptop walkthrough begins at the account screens. The user asks the assistant for available visits, selects a dentist, and checks **My appointments** after the booking is confirmed.

[Open the AWS walkthrough MP4 on GitHub](dental-agent-aws-walkthrough.mp4)

## Phone-to-laptop booking · 31 seconds

The user books an appointment with John Doe on a phone. On the laptop, they sign in to the same account and open **My appointments**, where the same visit is already listed.

[Open the phone-to-laptop MP4 on GitHub](dental-agent-phone-to-laptop.mp4)
